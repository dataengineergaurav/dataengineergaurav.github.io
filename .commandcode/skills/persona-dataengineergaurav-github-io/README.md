## What it says

- **Domain:** a lead-generation consulting site for senior data engineering and governed AI.
  The reader is a senior data or AI leader skimming for evidence.
- **Hard rule:** never name a client or employer in site prose, case studies, or posts; describe
  work by industry, scale, role, architecture and outcome. The published CV is the deliberate
  exception — its extended render names employers and the client-work roster.
- **Technical:** Jekyll + Bundler + GitHub Pages from `master`; `script/cibuild` is the
  verification gate (build, link check, content policy over PDFs too, the CV marker check, and the
  pipeline's own test suites); content ships as pull requests.
- **Derived artifacts:** the committed CV PDF is regenerated from the `CV-Development` project by
  `cv_sync.py` and checked against its `.version.json` marker in CI; neither should be hand-edited.
  `scrollcraft/` is scratch.
