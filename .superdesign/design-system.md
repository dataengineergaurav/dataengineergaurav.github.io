# Gaurav Gurjar Site Design System

## Direction

Editorial authority: calm, credible, personal, and technically rigorous. Preserve the current cream/forest/amber identity and generous whitespace. Avoid dashboard chrome, gradients beyond the existing paper texture, and app-like controls.

## Type and color

- Display: Georgia / Times New Roman, forest `#18372a`.
- Body: Avenir Next / Avenir / Segoe UI, forest `#18372a`.
- Muted copy: `#51665b`.
- Canvas: `#f5f0e5`; surfaces: `#ebe3d3`; accent: `#efb34e`.

## Layout and interaction

- Maximum page width: 74rem; reading width: 44rem.
- Large article cards are reserved for featured/recent content.
- Archive rows should be compact, separated by rules, and remain legible on mobile.
- Topic controls should use native links or buttons, visible keyboard focus, and a clear active state.
- Preserve semantic headings, minimum 44px action targets, and reduced-motion behavior.
