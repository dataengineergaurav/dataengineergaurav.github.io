# Components

The site has no component framework. Reuse the existing semantic patterns in Markdown/Liquid:

- `.eyebrow`: uppercase metadata label.
- `.button`: text link styled as a bordered action.
- `.insight-card`: featured article card with paper-deep background and amber top rule.
- `.prose`: narrow long-form reading column.
- `.cta-panel`: article-end consulting call to action.

Do not introduce a JavaScript component library.
